INSTALL

三步装好，
不用改代码。

插件只放在桌宠自己的目录里，不会写进启动器，也不会跟着启动器更新被覆盖。

01

下载并解压

下载 ZIP 后解压，会得到一个以插件 id 命名的文件夹，例如 lfelkeea.focus_guard。整个文件夹留着，别只拿里面的 main.py。

02

放进插件目录

右键桌宠 →「插件管理」→「打开插件目录」，把整个文件夹放进去。也可以手动放到桌宠的 data/plugins 下。

03

扫描并启用

回到插件管理点「重新扫描」，找到新插件，勾选「启用」。插件会立即运行；带设置面板的插件还会出现「设置」按钮，连接、白名单等配置都在里面填。不想要时取消勾选即可停止。

专注时间装好后会立刻开始第一段计时。默认专注 50 分钟、休息 5 分钟。想改时长，先退出桌宠，编辑 data/config.json 里 plugins.settings.lfelkeea.focus_guard 的 focus_minutes 和 break_minutes，保存后重新打开桌宠。每天完成多少段只记在本地，不会上传。

QQ 桥接要先装 SnowLuma，桌宠要 1.1.1 或更高。SnowLuma 是独立运行的 QQ → OneBot 桥，不包含在插件包里，也不允许二次打包。到 官方 Releases 下载 win-x64 完整包（自带 Node，开箱即用），按 Windows 部署说明登录 QQ。装好插件后打开「设置」面板，填 SnowLuma 的 HTTP 地址和 accessToken，事件地址 http://127.0.0.1:8766/onebot 面板里会自动算好并可一键复制，粘回 SnowLuma 即可。白名单、人格卡、记忆、黑话和 QQ 空间也都在面板里。插件 ZIP 里的 README.md 有逐项说明。

BUILD YOUR OWN

想自己写？
接口很小，够用。

一个插件就是一个文件夹：plugin.json 声明元信息和权限，main.py 暴露 setup(api)。不需要打包，也不需要改桌宠源码。

main.py python 
def setup(api):
    api.say("我上线了。")

    def remind():
        api.say("该喝水了。", 6000)
        api.action("nod")

    api.every(30 * 60 * 1000, remind)

BEFORE YOU ENABLE

插件是本机代码，
只启用你信得过的。

插件以你的 Windows 账户权限运行，能读取它被允许访问的内容，也能执行 Python 代码本身能做到的事。下载前看一眼来源和 main.py；来路不明的插件不要启用。站内插件都附了 SHA-256，下载后可以自行核对。
