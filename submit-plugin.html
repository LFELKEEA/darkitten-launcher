REVIEW CHECKLIST

审核会看什么

  • ZIP 根目录、plugin.json 和入口文件是否完整。
  • 权限是否和实际行为一致，有没有偷偷多要权限。
  • 是否读取、上传或记录不该碰的数据。
  • 外部依赖是否说明清楚，链接是否指向官方来源。
  • 描述、版本号和作者信息是否准确。
WILL BE REJECTED

这些会被退回

  • 包含可执行文件、脚本、密钥、config.json 或 data/。
  • 使用 lfelkeea. / example. 保留前缀。
  • 覆盖官方插件或别人的插件 id。
  • 权限和代码明显不符，或包含恶意行为。
  • 没有实际功能、只是空壳或重复投稿。

STEP 02 / GITHUB

到 GitHub 附上 ZIP，然后提交

浏览器不能直接把文件写进我们的仓库。下面的按钮会打开一个已经填好标题和元数据的投稿 Issue，你只需要把 ZIP 拖进去。

  1. 打开投稿页。点下面的按钮，登录 GitHub 后进入新建 Issue 页面。
  2. 粘贴正文。如果正文没有自动填好，点「复制正文」再粘贴进去。
  3. 拖入 ZIP。把刚才选择的 插件.zip 拖到正文的「插件包」区域，等 GitHub 显示上传完成。
  4. 提交。点 Submit new issue。自动校验结果会以评论出现在 Issue 里。
打开 GitHub 投稿页

ZIP 由 GitHub 托管，本站不保存投稿文件。审核通过后，维护者会评论 /approve， Actions 会再次校验并自动发布；退回时会说明原因。
