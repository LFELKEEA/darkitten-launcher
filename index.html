WHAT'S INSIDE

猫爪能碰到的地方，
都替你安排好了。

不只是“能启动游戏”。版本、加载器、Mod、整合包、皮肤、联机、服务端和更新，每一块都有对应的页面和兜底逻辑。

01

原版和三种加载器，一个地方装好

从 Mojang 清单读取正式版与快照；装完原版后可以直接在版本行绑定 Fabric、Forge 或 NeoForge。已有的版本文件夹、ZIP 也能拖进来。

  • 每个版本独立 mods、saves、config，互不影响
  • 自动判断 Java 版本，缺失时给出提示
  • BMCLAPI 镜像优先，官方源失败自动回退
  • 下载中断后继续，已完成文件不重下
VanillaFabricForgeNeoForge
02

双源模组仓库，前置和冲突一起管

Modrinth 与 CurseForge 同屏切换，按游戏版本、加载器和分类筛选 Mod、整合包、材质与光影。已安装的 Mod 可以启停、检查更新和修复冲突。

  • 必填前置一键跳转，缺哪个补哪个
  • 环境检查覆盖加载器混装、重复 modId、缺失前置
  • 更新检查逐项列出可用新版本
  • 冲突修复先备份再改，不直接动原文件
ModrinthCurseForge前置冲突修复
03

整合包拖进来，进度和任务都看得见

支持 Modrinth、CurseForge 整合包和本地 ZIP / 文件夹导入；下载中心集中显示速度、进度和后台任务，导入期间可以取消，下次继续。

  • 大文件多连接，小文件按体积分配并发
  • 依赖库按已处理字节计算进度，不会长时间卡住
  • ZIP 并行解压，导入完成立即写入版本 JSON
  • 下载卡住自动重试，不用守着窗口
整合包断点续传下载中心
04

64×64 皮肤，直接看 3D 效果

导入 PNG 自动识别 Classic / Slim 模型，支持 64×64 与 64×32。LittleSkin 角色与游戏账户共用登录状态，不用再单独登录一次。

  • 待机、行走、转身三种动作，可拖动旋转、滚轮缩放
  • 皮肤库保存多套皮肤，点一下切换
  • 正版账户可上传 Mojang，离线账户本地加载
  • LittleSkin 密码不经过启动器，令牌用 DPAPI 加密
LittleSkin3D 预览ClassicSlim
05

房间号一贴，朋友就能进来

内置 P2P 直连与樱花穿透两套方案。P2P 不需要樱花账户，房主开房后把 U/XXXX-XXXX-XXXX-XXXX 房间号发给朋友即可组网。

  • 自动发现房主，优先直连，失败走公共节点中继
  • 显示玩家列表、直连/中继人数和延迟
  • 可只允许直连，或隐藏本机地址只走中继
  • 房主退出游戏自动关房，启动器退出回收进程
EasyTierP2P樱花穿透房间号
06

开服、看控制台、改配置，都在启动器里

Paper、Spigot、Fabric、Forge、NeoForge 服务端统一管理。控制台直接输入命令，插件或 Mod 可以在页面里搜索下载。

  • server.properties 和插件配置可视化编辑，内置中文说明
  • 保存前自动备份原文件，改错可以恢复
  • 世界、玩家数据、插件和配置可整包 ZIP 备份 / 导入
  • 运行状态、PID、端口和日志一屏可见
PaperSpigotFabricForgeNeoForge
07

Ctrl+K，常用操作不用翻菜单

快捷命令面板可以启动游戏、打开任意页面、创建世界快照、生成诊断包或切换主题；安全模式会临时禁用 Mod，退出后自动恢复。

  • 世界与配置快照，恢复时只覆盖同名文件
  • 诊断包收集日志、系统和 Mod 信息，自动脱敏令牌
  • 运行日志随时展开，排查启动问题
  • 浅色 / 深色主题一键切换
Ctrl+K快照诊断包安全模式
08

更新只换代码，存档和账户原地不动

更新时只替换 app.py、darkitten/、assets/ 和依赖清单；config.json、social.json、minecraft/、skins/、servers/ 不会被覆盖。先校验 SHA-256，失败自动回滚。

  • 关闭窗口可选后台运行、退出程序或取消
  • 同一用户只允许一个实例，重复启动会唤醒已有窗口
  • 更新完成后自动重新打开启动器
  • 桌宠独立更新，data/config.json 保留

MOD AGENT

把恶魔小猫工坊放进桌面。

恶魔小猫工坊是独立运行的 Minecraft Java 模组开发 Agent，只做 Fabric / NeoForge / Architectury。它会先确认 MC 版本、加载器和 Mod ID，再按工程结构生成完整文件；所有写入先进入待确认列表，覆盖前自动备份。内置技能、连接器与知识库，可以从下载站、GitHub 或启动器获取，并在程序内检查更新。0.1.4 加了「编译运行」页，可以直接执行 build / runClient / runServer / runDatagen 并实时看日志；0.1.5 又补了两枚按钮——工程没有构建脚本时点「让助手补全配置」，自动切到对话按版本和加载器生成 settings.gradle / build.gradle / gradle.properties；本机没装 Gradle 时点「生成 Wrapper」，写入内置的 Gradle 8.10.2 Wrapper，第一次编译再自动下载发行包。0.1.6 修复加速器环境下的证书问题：Gradle 下载遇到 `PKIX path building failed` 会自动改用 Windows 证书库重试，页面上也留了手动开关。0.1.7 把内置 Wrapper 升到 Gradle 9.8.2，和当前 Fabric loom 的要求对齐；编译报「requires at least Gradle X」时，页面会直接告诉你当前版本和该点哪个按钮。0.2.0 把这些步骤收成「一键准备」：缺 JDK 就自动下载 Temurin 21 装到程序自己的 data 目录，缺 Wrapper 就补齐，缺 Gradle 发行包就从国内镜像下载并校验 SHA-256；点编译、开发客户端、开发服务端或数据生成时都会先自动准备，再直接执行。0.2.1 加了「删除工程」：二次确认后把工程目录移到 Windows 回收站，并清掉最近记录和对话记录；有生成或 Gradle 任务在跑时会先拦住。0.3.0 把「记忆库」换成「知识库」：可以直接导入 txt / md / docx / pdf 和代码配置文件，程序自动提取正文并分片；每轮对话前自动检索最相关资料，做模组时优先参考你导入的规范、笔记和文档，需要细节还能按关键词查或按编号读全文。0.3.1 继续加了模组 JAR 分析：直接把现成模组丢进知识库，程序会提取 fabric.mod.json / mods.toml、语言和资源文件、类名与继承关系、字段、方法、引用类、调用到的 API 和字符串常量；做兼容、移植或复刻功能时，助手可以直接按类名和功能检索实现结构。JAR 不反编译方法体，需要完整源码时可以再导入对应的 -sources.jar。0.3.2 补上了源码反编译：导入 JAR 时自动调用内置的 Vineflower 1.12.0，把类还原成可检索的 Java 源码，方法体、字段读写和调用链都能直接查；反编译在本机执行，不上传文件。需要 JDK 17 或更高，没有时仍可只导入类结构，到「环境」页一键准备后再重新导入即可。Fabric 模组里的 class_1234 / method_5678 是 intermediary 名称，需要对照工程当前的 Yarn / Mojmap 映射。0.3.3 解决「导入了 JAR 但助手不知道逻辑」：每份 JAR 资料开头新增「模组速览」，写清模组 ID、入口类、重点类和中文字符串提示，再按包列出完整类索引，最后才是反编译源码；中文提问会额外映射到 Possession / Skin / Render / Packet 等英文标识符，单个 JAR 文档最多返回 4 个片段，关键词没命中时自动把速览和类索引交给助手。旧版导入的 JAR 会从已有类结构自动补类索引，重新导入同一个 JAR 即可覆盖旧记录并获得完整源码。0.3.4 把反编译结果真正放进工程：知识库页选中 JAR 点「反编译到工程」，主 JAR 和 META-INF/jars 里属于模组自己的内嵌模块会一起展开成 .java，按原包路径写到 reference/decompiled/<JAR 名>/，并生成 INDEX.md；这个目录不参与编译，只作为迁移参考。对话里也可以直接让助手调用 decompile_jar。PoHypSkin 实测主 JAR 106 个文件、内嵌 skinblade 模块 17 个，modd0bde892 和 mod7e1537e4 两个包都能展开。
